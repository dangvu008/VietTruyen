# Canon / Intent Memory Contract

Before any chapter contract is produced, load in this order:

1. `authority-model.yaml`
2. `10-hard-constraints.yaml`
3. `03-dream-world.yaml`
4. `story-framework.md`
5. relevant current arc under `../planning/`
6. accepted history/state/knowledge/graph from story memory

Do not merge planning with history.

- CANON = usable constraint/fact.
- ACCEPTED_HISTORY = happened in accepted prose.
- PLANNED = intended future, not yet happened.
- PROPOSED = optional idea only.
- UNKNOWN = intentionally unresolved; agent may not invent the answer.

A chapter review must test both directions: consistency with canon/intent and consistency with accepted history/memory. If either fails, HOLD.
